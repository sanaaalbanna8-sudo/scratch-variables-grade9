المعادلة الثانية: النتيجة = النتيجة + 1

بعد التنفيذ، القيمة المخزّنة:

3 + 1 = 4. التعيين أولًا ثم الزيادة.

القيمة 3 ونريد −2. التعديل:

3 + (−5) = −2. ويمكن مباشرة: اجعل النتيجة مساويًا −2.
